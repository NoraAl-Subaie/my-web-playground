🧱 HTML: هيكل الصفحة

HTML هي اللغة المسؤولة عن هيكل الصفحة ومحتواها: العناوين والفقرات والروابط والصور.

<h1>Hello, Web!</h1>
<p>This is my first page.</p>

Hello, Web!

This is my first page.

🎨 CSS: تنسيق الصفحة

CSS مسؤولة عن الألوان والخطوط والتنسيق. جرّب بنفسك:

h1 {
    color: purple;
}

Hello, Web!

⚡ JavaScript: التفاعل

JavaScript تضيف السلوك والتفاعل للصفحة. اضغط الزر وشوف النص يتغير:

document.querySelector("h1")
.textContent = "Hello, JS!";

Hello, Web!

↔️ Frontend vs Backend

الصفحة لها جانبان. اضغط على كل بطاقة عشان تشوف المثال:

🖥️ Frontend

اللي تشوفه وتتفاعل معه في الموقع.

مثال (متجر إلكتروني): المنتجات والأزرار وسلة الشراء.

🗄️ Backend

اللي يصير خلف الواجهة.

مثال (متجر إلكتروني): التحقق من تسجيل الدخول ومعالجة الطلب وحفظه في قاعدة البيانات.
